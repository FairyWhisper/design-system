# FairyWhisper Toolkit - Design System

## FairyWhisper Toolkit

The FairyWhisper Toolkit is a collection of reusable, cross‑development assets, decisions, logic, and components for FairyWhisper projects.

Its purpose is to provide consistent visual identity, modular UI/UX patterns, and shared logic across all FairyWhisper developments. As new projects and coursework arise, this toolkit ensures that design choices, components, and branding remain cohesive and repeatable.

## Design-System

The FairyWhisper Design System is a token‑based, comprehensive visual language. It provides the foundational styles and components that support cohesion across all FairyWhisper applications.

### Structure

The Design-System is built with React + Vite.

design-system/
  src/
    PreviewPalette.jsx
    fairywhisper-tokens.css
    main.jsx
    App.jsx
    assets/

## Using Design-System

Design-system is built using React + Vite, it can be run using:

    npm install
    npm run dev

## Foundations

Design-System will include the following;

- Colour tokens
- Typography tokens
- Spacing tokens
- Radii tokens
- Shadow tokens
- Component previews
- Documentation pages
